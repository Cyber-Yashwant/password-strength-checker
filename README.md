# Password Strength Checker

A Python-based cybersecurity project that evaluates password strength.

## Features
- Password length check
- Uppercase letter detection
- Number detection
- Symbol detection
- Common password detection
- Weak, Medium and Strong classification
- Hidden password input

## Technologies
- Python
- String Handling
- Conditional Logic

## How to Run

```bash
python password_checker.py

## Project Purpose

This project demonstrates basic cybersecurity concepts including
password validation, character analysis, conditional logic, and
password strength classification.
